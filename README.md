# Addition Facts in Other Bases

A quick practice interactive. Each problem is two nonzero single digits added in a base from 2 to 9. Students type the answer in that base, or tap Show me to see it with a set model: circles are grouped into one group of the base (the 10s digit) with the leftovers as the 1s digit. Then a new problem appears.

Open `index.html` in a browser, no build step needed.
